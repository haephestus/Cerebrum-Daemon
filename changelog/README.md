# Changelog

Human-readable record of substantive changes, one file per day
(`YYYY-MM-DD.md`). Each entry lists **what** changed, **why**, and the
**files** touched, grouped by change-set. This complements git history — git
tells you the exact diff; these entries tell you the intent and the shape of
a day's work at a glance.

Convention for each change-set:

- **What** — one or two lines on the change.
- **Why** — the problem it solves.
- **Files** — paths touched (relative to `src/` unless noted), with a note each.
- **Verified** — how it was checked (tests, compile, smoke).

Newest day first within the folder listing; newest change-set first within a day.
